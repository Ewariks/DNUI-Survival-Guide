# 奖学金

> 本文整理自东软睿新发〔2025〕15 号《高校奖学金管理办法》（V1.0，2025 年 3 月 28 日）与《学生手册》中的《学生奖励办法》。**政策会修订，请以你查到的最新版本为准。**

## 学校有哪些奖学金

| 类别 | 说明 |
| --- | --- |
| **华天奖学金** | 由李华天教授设立，是**学生奖学金的最高荣誉** |
| **东软睿新奖学金** | 东软睿新科技集团设立，分一等、二等、三等 |
| 国家奖学金 / 省政府奖学金 / 国家励志奖学金 | 按上级部门规定执行 |
| 新生奖学金、特别奖学金 | 由学校提出方案、集团批准后执行 |

## 金额与名额

**华天奖学金**（特等奖学金）：

- **10000 元/人**；
- 每学年度**约 10 人**，由集团依据当年各高校总体在校生规模确定；
- 评审由**集团最终审批**。

**东软睿新奖学金**：

| 等级 | 金额 |
| --- | --- |
| 一等 | 5000 元 |
| 二等 | 2000 元 |
| 三等 | 1000 元 |

各高校可根据实际情况适度调整，但需报集团备案。

## 评选条件

**共同的底线**：

- 品行端正、讲诚信、尊敬师长、团结同学，**操行考核成绩良好（含）以上**；
- 评选学年度内**无任何纪律处分**；
- **无不及格课程**。

**成绩门槛**：

| 奖学金 | 综合平均成绩要求 |
| --- | --- |
| 华天奖学金 | **80 分及以上**（**不含体育课**），且无不及格课程 |
| 东软睿新奖学金 | **60 分及以上**，且无不及格课程 |

评选以**学习成绩为基本依据**，分年级、专业、层次**由高到低排名、择优评选**。学习成绩与操行成绩的具体计算办法按《学生手册》执行，学校可另设加分标准。

> [!NOTE]
> **华天奖学金的综合平均成绩不含体育课**——这是《高校奖学金管理办法》里明确写的。但**学年评优**反过来会**单独**给体育课设一条单科线（三好学生 80 分、十佳大学生 75 分等），所以体育分对评优有影响、对奖学金没有。见[体育课、校园跑与体质测试](/study/pe-and-fitness)。

> [!WARNING]
> 原则上**同一学生不应重复获奖**；特殊情况需要说明原因，并经学校奖学金评审委员会审批。

## 校长创新奖

这是一个**单独的奖项**，由**学生发展与服务部**负责，依据《大连东软信息学院校长创新奖评选办法》（东软校学发〔2024〕16 号，V2.0）。它不在集团的奖学金体系里，评选条件和上面几项完全不同。

**硬门槛**（必须全部满足）：

- 具有学校正式学籍的全日制在校本专科学生；
- 热爱祖国，拥护中国共产党领导，有较高的思想政治素质；
- 遵守国家法律法规和校规校纪，**尚在处分期限内的学生不得参评**；
- 学年必修课（包括专业限选课）**未有不及格课程**。

**创新成果**——上面四条都满足的前提下，下面四项**任意满足一项**即可申报：

| 方向 | 具体要求 |
| --- | --- |
| 学术 | 以独立作者或第一作者（或导师第一、本人第二）在学校认定的 **C 级期刊至少 2 篇**，或 **B 级及以上期刊至少 1 篇** |
| 发明创造 | 以大连东软信息学院为第一完成单位、本人为第一完成人（或导师第一、本人第二），获**实用新型专利或发明专利授权 1 项** |
| 学科竞赛 | 独立或作为主力队员（排名第一）参加学科竞赛，获**榜单竞赛国家级一等奖以上**（按校内认定奖励等级） |
| 大创项目 | 作为项目负责人获**国家级重点支持大创项目**立项 |

**注意最后两条的量级**：竞赛要走的是「**榜单竞赛**国家级一等奖以上」，大创要的是「**国家级重点支持**」项目——门槛明显高于其他奖项。

**名额极少**：领导小组综合候选人材料和学院推荐意见，**择优评选出 1 人**，并在全校范围内公示。每学年评选表彰 1 次。申报还需要提交不少于 1000 字的个人事迹和照片。

## 评选时间

**每年 7—10 月**进行奖学金的评选和发放。

## 关于大一

据 Yunlk 的观察：**大一新生能评的主要是东软睿新奖学金的最低等级。**

原因不难理解——刚入学没有成绩与综测积累，华天奖学金和东软睿新的高等级通常轮不到大一。**大一先把成绩和素拓分打扎实，比盯着奖学金更实际。**

## 一条容易被忽略的关系

[英语课与四六级](/study/english) 那页提到过：**大四评选上一学年奖学金及行政评优，要求通过 CET-4。**

也就是说，四级不只是「过一场考试」，它和大四的评奖评优是绑定的。
