# 学年评优

> 本文整理自《学生手册》中的《学生奖励办法》。**学生手册每年修订，请以你所在年级的最新版本为准。**

## 奖项设置

**优秀个人奖**（15 项）：

十佳大学生、三好学生、优秀学生干部、校长创新奖个人奖、创新创业奖、科技创新奖、特殊贡献奖、学习优胜奖、优秀毕业生、十佳科技创新、十佳外语之星、十佳文艺之星、十佳体育之星、十佳社会实践、晨读优秀领读员。

**优秀集体奖**（6 项）：

学风标兵班、先进班集体、校长创新奖集体奖、外语晨读课先进班集体、晚自习课先进班集体、文明寝室和优良学风寝室。

> [!NOTE]
> 优秀团员、优秀团干部、优秀学生会干部、学管会优秀干部、优秀社团个人/干部等奖项**由校团委另行规定**，不在本办法范围内。

## 主要奖项的门槛

评选有两个共同前提：**思想品德与校规校纪方面达标**（尚在处分期限内的学生不得参评），以及**素质教育考核成绩**达到相应等级。

| 奖项 | 关键门槛 |
| --- | --- |
| **十佳大学生**（在校学生最高奖项） | 从毕业年级评选；素质教育考核**优秀**；前三学年必修课（含专业限选课）平均成绩达**同一专业年级前 3%**；体育 75+；寝室卫生 85+ |
| **三好学生** | 素质教育考核**良好以上**；学年必修课平均分 **80+** 且各科 **65+**；体育 80+；寝室卫生 85+ |
| **优秀学生干部** | 限副部长及以上干部等；素质教育考核**优秀**；单科 60+ 且必修课平均分 **75+**，或各单科均 70+；体育 70+ |
| **学习优胜奖** | 素质教育考核良好以上；必修课平均分 **85+** 且单科 65+；体育 70+ |
| **科技创新奖** | 素质教育考核良好以上；以第一作者在省级以上期刊发表论文，**或学科竞赛获市级二等奖 / 省级三等奖 / 国家级优秀奖及以上**，或获得专利等 |
| **特殊贡献奖** | 代表学校参加文体比赛，获市级个人三等奖及以上、省级和国家级优秀奖及以上 |
| **创新创业奖** | 已登记注册并实际经营，或有完备的创业计划并已开始实施，或在各级创新创业活动中获市级及以上表彰 |
| **优秀毕业生** | 在校期间至少两次获校级优秀学生个人奖；达到并保持《国家体育锻炼标准》；毕业论文**良好以上** |

评奖按**综合评优成绩**排序（见[素质学分与竞赛积分](/study/quality-credits)），分数列前者可优先选择评优项目。

注意体育那一列：**它是单科成绩的硬门槛**，和「综合平均成绩不含体育课」的奖学金口径不一样。体育分怎么构成、为什么容易吃亏，见[体育课、校园跑与体质测试](/study/pe-and-fitness)。
