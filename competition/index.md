# 竞赛

这里将整理面向在校学生的各类竞赛信息与参赛经验，例如程序设计竞赛、数学建模、创新创业类比赛等。

内容正在持续完善。欢迎通过 GitHub Pull Request 参与贡献。

## 计划整理的话题

以下为栏目规划，具体内容以各页面实际发布为准：

- 常见竞赛类型与选择（ACM-ICPC / 蓝桥杯 / 数学建模 / 挑战杯等）
- 组队、报名与备赛流程
- 参赛经验分享
- 竞赛经历与升学、就业的关系

> 涉及具体报名条件、赛制与时间的内容，请以官方通知为准。

## 参与贡献
