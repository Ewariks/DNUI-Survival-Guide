# 集创赛

集创赛的全称是**全国大学生集成电路创新创业大赛**，由工业和信息化部人才交流中心主办。它的组织形式与一般学科竞赛差别较大：**采用企业命题制**，参赛队伍选择一个企业赛题，按赛题要求完成设计或实现，再经初赛、分赛区决赛、全国总决赛逐级评审。

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 全称 | 全国大学生集成电路创新创业大赛 |
| 主办 | 工业和信息化部人才交流中心 |

| 赛制 | 初赛 → 分赛区决赛 → 全国总决赛 |
| 形式 | 企业命题，团队参赛 |

## 参赛对象与赛区

参赛对象为集成电路、微电子、电子科学与技术及相关专业（包括但不限于电子信息工程、通信工程、计算机科学与技术、自动化、数学与应用数学、信息与计算科学等）的**在校专科生、本科生、硕士研究生和博士研究生**。

大赛划分为 7 个赛区，学生根据学校所在省份参加分赛区决赛：

| 赛区 | 覆盖地区 |
| --- | --- |
| 华北赛区 | 河北、北京、天津、山东 |
| 东北赛区 | 黑龙江、吉林、辽宁 |
| 西北赛区 | 山西、陕西、宁夏、青海、甘肃、新疆、内蒙古 |
| 西南赛区 | 四川、重庆、云南、贵州、西藏 |
| 华中赛区 | 河南、湖北、湖南、安徽、江西 |
| 华南赛区 | 广东、广西、福建、海南、港澳台地区 |
| 华东赛区 | 上海、江苏、浙江 |

## 组队与组别

- 学生**自行组队**，可以跨校组队；
- 每个团队 **1~3 人**，每队指导教师 **1~2 人**；
- 报名表需要**学校或学院盖章**；
- **团队成员均为本科生及以下的队伍划入 A 组**；团队中有 1 名或以上研究生的划入 **B 组**。各赛题会规定可报名的组别，只允许符合组别的队伍报名；
- 除集成电路芯创成果方向外，**每位同学只能参加一个团队**，每队可选择一个题目。

## 日程安排（第十届）

| 节点 | 时间 |
| --- | --- |
| 报名 | 1 月至 3 月，截止 3 月 31 日 |
| 中期检查 | 4 月中旬，统计作品基本情况与进度 |
| 校内选拔赛（可选） | 5 月 7 日之前 |
| 初赛作品提交 | 5 月 7 日截止，评审在 5 月 |
| 分赛区决赛 | 7 月 |
| 全国总决赛 | 8 月下旬 |

其中**校内选拔赛是可选环节**：原则上参赛队伍数超过 20 支的院校可申请举办；一旦申请通过，该校参赛队伍**必须**参加校内选拔赛。校内选拔赛的成绩不计入后续比赛结果。

## 参赛费用

- **报名阶段每队须交 300 元押金**，目的是避免浪费赛事资源；
- 如果团队按要求完成赛程但未获得分赛区奖项，**押金在分赛区决赛结束后 30 个工作日内退回**；若中途弃赛则不予退还；
- 通过初赛的团队须交 300 元参赛费（押金转为参赛费），通过报名平台「赛氪」统一缴纳；
- 选手及指导老师在校赛、分赛区决赛和全国总决赛期间的交通、住宿、用餐等费用自理。

## 评审方式

| 阶段 | 评审方式 |
| --- | --- |
| 初赛 | 命题企业技术专家线上技术评分，据此确定晋级名单 |
| 分赛区决赛 | 分赛区承办方组织专家评审，结合现场评审得分与初赛技术评分确定成绩 |
| 全国总决赛 | 组委会组织专家，根据演讲汇报、作品演示、提问等环节的综合表现确定成绩 |

分赛区一、二、三等奖的获奖比例约为初赛晋级队伍数量的 20%、30%、50%。全国总决赛各题目均设一、二、三等奖，并由评审组从企业命题一等奖团队中挑选一支授予**企业大奖**。

> [!WARNING]
> 参赛作品中有两条硬性要求：**不允许出现学校、指导老师的相关信息**；借鉴或采用他人公开发表的论文和成果**必须注明来源**。两者一经发现均作扣分处理。

## 平台支持

大赛为参赛学生提供若干支持计划，包括免费技术培训、部分优秀项目的免费流片资格、投资与行业资源对接，以及获奖选手优先获得企业实习就业机会。

## 参赛经验

> 以下为社团成员 Yunlk（2025 级）的参赛经历，仅供参考。

### 组队

一般是 **3 人 1 队**。组队方式不是提前拉好队伍，而是**先各自报名，再开会，在报名的人里面自己找队友**。常见的搭配是**一个学长带两个学弟**——有经验的人先带一轮，后面的人就接得上。

### 选题决定难度

集创赛是**企业命题制**：需要什么能力，完全看你报的是**哪家企业的哪道题**。命题会写明这道题的技术要求，你要先读题，再判断自己有没有对应的功底。

以我参加的赛道为例，实际用到的是这几类能力：

- **读芯片数据手册**：赛题围绕具体芯片展开，要先从手册里把关键参数、时序和测试条件读出来；
- **硬件设计**：按测试平台（ATE）的要求做 PCB 和原理图；
- **写测试向量**：根据测试平台编写测试向量，让芯片按预期被验证；
- **做文档**：方案、测试结果与结论都要写成规范的文档，这是评分的一部分；
- **临时学新工具**：我们那个赛道还要用到 LabVIEW，得自己现学。

也就是说，**这是一项对综合工程能力要求很高的比赛**，只会在编辑器里写代码远远不够。建议的流程是：**先看命题要求 → 对照自己会什么 → 再决定报哪一道题**。
