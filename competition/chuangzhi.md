# 传智杯

「传智杯」全国 IT 技能大赛的特点是**多赛道**：除了程序设计，还覆盖网页开发、智能办公、小程序、嵌入式、UI 设计、数字创意等方向。算法方向的学生通常报的是**程序设计挑战赛**。

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 全称 | 「传智杯」全国 IT 技能大赛（大赛官网同时标注为「全国大学生计算机应用能力与数字素养大赛」） |
| 官网 | [boxuegu.com/match](https://www.boxuegu.com/match/) |
| 赛程 | 报名 → 赛前备赛 → 院校自行选拔 → 省赛 → 国赛 → 颁奖典礼 |
| 定位 | 官网介绍为教育部认可的高校「国赛」榜单赛事，程序设计赛道对标 ACM |
| 学校认定类别 | **A 类**（名单中为「全国大学生计算机应用能力与数字素养大赛」，见[竞赛类别与课程加分](/competition/levels)） |

## 赛事规模

按大赛官网的说明：

- 已连续举办 **8 届**；
- 累计参赛院校 **1700+ 所**，覆盖 **87%** 的「双一流」高校；
- 累计参赛大学生 **230000+ 人次**。

我校的官方报道也提到，这项赛事覆盖软件开发、人工智能应用、网页开发、智能办公、数字创意设计等多个方向，**全国千余所本专科院校组队参赛**。

## 赛道设置

从我校官方公布的获奖名单看，实际开设的赛道包括：

| 方向 | 赛道 |
| --- | --- |
| 程序设计 | 程序设计挑战赛 |
| 网页与小程序 | AI WEB 网页开发挑战赛、AI 微信小程序开发挑战赛 |
| 智能办公与 AI 应用 | WPS 智能办公能力挑战赛、AI 大模型创新应用挑战赛 |
| 嵌入式与系统 | AIoT 嵌入式系统创新大赛、HarmonyOS Codelabs 挑战赛 |
| 数字创意设计 | UI 设计挑战赛、微短剧设计挑战赛、动漫设计挑战赛、传统非遗设计挑战赛 |

多赛道意味着**即使算法方向竞争激烈，也可以换到其他赛道去争取成绩**。

## 赛程与时间

以大赛官网公布的第九届安排为例：

| 阶段 | 时间 |
| --- | --- |
| 报名期 | 2026 年 7—11 月 |
| 备赛期 | 2026 年 7—11 月 |
| 院校自行选拔 | 2026 年 7—11 月（可由赛点院校自行组织） |
| 省赛 | 2026 年 11 月，在赛点院校参加 |
| 国赛 | 2026 年 12 月，在赛点院校参加 |
| 全国颁奖典礼 | 2027 年 |

其中**院校自行选拔**是一个独立环节，由赛点院校自行组织，不通过选拔就无法进入后面的省赛。

> [!WARNING]
> 赛程与时间逐届调整，上表为第九届的口径。报名与各赛道要求请以大赛官网和学校通知为准。

## 主办与组织

按我校官方报道，这项赛事由**全国高等院校计算机基础教育研究会、全国高等学校计算机教育研究会、工业和信息化职业教育教学指导委员会计算机分委会、《计算机教育》杂志社**联合主办。大赛官网显示，竞赛指导委员会主任由全国高等院校计算机基础教育研究会会长担任。

## 参赛经验

> 以下为 Yunlk 的参赛经历，仅供参考。

- **参赛环节**：我只参加了**校内选拔赛**，赛题比较基础，直接 AK（全部通过）；
- **后续**：之后没有再参加省赛，所以省赛与国赛的实际情况我这里没有一手经验。

不过有一点可以确认：**传智杯的校赛门槛不高**，校赛题目能稳定做出来，就有机会往后走。而且它是多赛道比赛，如果算法方向竞争激烈，也可以转向网页开发、智能办公、嵌入式、数字创意设计等赛道去争取成绩。
