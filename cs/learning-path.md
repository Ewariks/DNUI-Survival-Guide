# 从零开始学编程：一条自学路线

> 以下路线来自 Yunlk，参加过算法竞赛。个人路线，不是唯一答案，仅供参考。

## 先补一层底子：计算机组成原理

**建议先学一点计算机组成原理**，最起码要搞懂**内存**的概念。

很多人一上来就学语法，结果遇到指针、数组越界、值传递与引用传递时全靠死记——知道内存里发生了什么，这些就不需要背了。

## 语言顺序：C → C++ → 再扩展

1. **C 语言**：先搞懂输入输出、分支、循环这些基本功。C 的语法量不大，适合作为第一门语言；
2. **C++**：在 C 之上学 **STL 库**和**算法思想**——这是打算法竞赛的必备工具；
3. **再学几门**：推荐看看 **Go、Rust、Python**。不同语言解决不同问题，多学一门会明显拓宽思路。

## 如果要打算法竞赛

**这是一个长期的过程，一定不要放弃。**

竞赛能力不像考试可以突击，靠的是持续投入。具体赛事与备赛方式见[竞赛栏目](/competition/)。

## 学计算机需要一种心理状态

这是最想分享的一点：

> 计算机里的所有东西都是人做出来的。**别人能想出来的，我也一定能想得出来。**
>
> 这里没有任何黑魔法，所有的东西只不过是我现在不知道而已——总有一天，我会把所有的细节、所有内部的东西全都搞明白。

大学里大家都很迷茫，都走错过弯路，这很正常。**最后只要成为你想成为的人就够了。**
