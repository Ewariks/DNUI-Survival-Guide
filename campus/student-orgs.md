# 学生组织

DNUI 的学生组织大致分为三层：**校级组织**、**院级组织**和**学生社团**。本页整理分类框架与官方入口，具体组织部门与社团名单正在持续整理中。

> [!TIP]
> 在决定要不要参加之前，推荐先读经验分享栏目的[《社团值不值得参加》](/experience/clubs)。

## 校级学生组织

校级组织由**校团委**指导，面向全校学生运行和纳新：

| 组织 | 说明 |
| --- | --- |
| 校团委学生会 | 学校层面的学生组织，每届通过公开选拔产生学生骨干，纳新通知一般发布于[校团委网站](https://xtw.neusoft.edu.cn/) |
| 学生代表大会 | 学生参与学校民主管理的代表大会机制 |

部门设置、选拔条件与纳新时间每学年可能调整，以校团委当年通知为准。

## 院级学生组织

各学院设有**团委学生会**等院级组织，在本学院范围内开展活动与纳新（如人工智能学院团委学生会等），由所在学院指导。学校目前设置的学院（来源：[学校官网导航](https://www.neusoft.edu.cn/)）：

- 人工智能学院
- 软件学院
- 信息与商务管理学院
- 智能与电子工程学院
- 数字艺术与设计学院
- 外国语学院
- 健康医疗科技学院
- 应用技术学院
- 创新创业学院（SOVO）
- 基础教学学院
- 马克思主义学院
- 国际教育学院
- 继续教育学院

院级组织的纳新一般在学年初，留意所在学院网站和通知群。

## 学生社团

据[校团委介绍](https://xtw.neusoft.edu.cn/2026_07/30_10/content-50124.html)，学校现有**近百个学生社团**，覆盖七大领域：

| 类别 | 主要方向 |
| --- | --- |
| 思想政治类 | 理论学习与社会实践，如国旗护卫、法治宣传、红色主题等方向 |
| 学术科技类 | 机器人、人工智能、大数据、网络安全、游戏开发等技术方向，项目驱动并对接学科竞赛；**数量占比最高**，新兴领域可全年申请注册成立 |
| 文化艺术类 | 艺术团、话剧、汉服、摄影、美术创作、模型设计等 |
| 体育竞技类 | 篮球、武术、轮滑、飞盘、棒球、滑板等，有机会承办校级体育赛事 |
| 志愿公益类 | 社区服务、急救培训、流浪动物救助等志愿服务 |
| 自律互助类 | 心理健康、语言学习、文学阅读、校友服务等朋辈互助 |
| 创新创业类 | 依托大学生创业中心（SOVO），覆盖创意孵化、产品研发、企业管理等环节 |

每年一度的**「社团嘉年华」**是各社团集中展演和纳新的主要场合。

具体社团名单与介绍正在整理中。欢迎补充你参加过的社团（注明来源或个人经历），贡献方式见[参与贡献](/contribute/)。

## 怎么加入

1. **学生社团**：关注学年初的社团嘉年华及各社团纳新推送，现场或线上报名；
2. **校级 / 院级组织**：关注[校团委网站](https://xtw.neusoft.edu.cn/)与所在学院的纳新通知，通常有报名、面试等环节；
3. **没有感兴趣的社团？** 学术科技类社团支持全年申请注册成立，满足条件可以自己发起。
