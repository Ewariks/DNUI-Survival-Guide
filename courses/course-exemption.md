# 课程免听

> 本文整理自《**电子与机器人工程系**课程免听实施细则》。**各系细则可能不同**，其他院系的同学请以自己系部的规定为准。

## 核心原则：免听不免考

**免听不等于免考。**

通过认定后，你可以**免听课程的常规课堂教学与平时作业**，但**必须参加课程专项答辩**——**答辩成绩就是这门课的最终成绩**。

这决定了它的性质：不是「跳过一门课」，而是**用项目实践换取一次答辩机会**。

## 什么情况可以申请

细则适用于以下三种情形（针对与项目高度关联的课程）：

| 情形 | 说明 |
| --- | --- |
| **学科竞赛** | 参与电子、机器人、智能制造等相关官方认可学科竞赛，作为参赛队员（含核心成员） |
| **教师科研项目** | 参与本系教师主持的科研项目，承担实质性研究工作 |
| **创新创业项目** | 主持或核心参与国家级、省级、校级大创项目及其他经系部认可的项目 |

> [!TIP]
> **不以是否获奖、是否结题为前提。** 答辩只针对你参与的项目本身，考查你通过项目掌握了哪些课程相关知识与技能；竞赛获奖与项目成果按学校其他规定单独执行，不与答辩成绩挂钩。
>
> 也就是说，**没拿奖也能申请**——很多人以为必须有奖状，其实不需要。

## 申请条件

需要同时满足：

- **课程结束前能完成全部项目流程**，并有完整成果（竞赛报告、作品、过程材料、科研报告、论文、专利、结题材料等）；
- 项目内容与所申请免听课程的**教学大纲、核心知识点、实践要求高度契合**；
- **未修读过该课程**、未参加该课程任何形式的考核，无违纪处分及学术不端行为。

## 什么时候申请

**每学期集中受理一次**，需在拟免听课程**开课前 1-2 周**提交申请，**逾期不予受理**。

> [!WARNING]
> 时间点很关键：**要在开课前申请**，不是学期中。等发现课业冲突了再去申请就来不及了。

## 申请材料

纸质版与电子版各一套：**《课程免听申请表》**＋**项目参与及成果证明**＋**个人学业相关证明**。

按申请类型另需提供：

| 类型 | 需要提供 |
| --- | --- |
| 学科竞赛类 | 竞赛参与及成果完成进度证明（**无需获奖证书**） |
| 教师科研项目类 | 指导教师出具的项目参与证明、贡献说明、科研报告或成果进度说明 |
| 创新创业项目类 | 项目立项证明、参与证明、成果报告或材料进度说明 |

## 评审流程

```text
提交申请 → 材料初审（开课前 1 周内）→ 联合评估（开课前 3 个工作日）
→ 结果公示 3 个工作日 → 获得免听资格 → 学期末考核周参加答辩
```

联合评估由**系部教学委员会与对应课程组**共同进行，重点核查项目与课程的关联性、参与真实性及贡献度。

## 答辩怎么答

- **形式**：PPT 陈述 **8-10 分钟** ＋ 答辩小组提问 **5-8 分钟**；
- **内容**：项目背景、本人承担的工作、实施过程、**运用到的课程相关知识与技能**、成果展示与反思；
- **不考核**竞赛获奖情况、项目结题等级或科研成果级别；
- 无故缺席视为答辩失败，**可以申请一次补答辩**。

## 成绩怎么算

**答辩成绩采用百分制，就是这门课的最终成绩。**

- **60 分及以上**：及格，获得对应课程学分；
- **60 分以下**：免听失败，**需重新修读该课程**。

## 中途退出要恢复修读

如果中途退赛、退出项目或被除名，免听资格终止，并且**要按常规方式补回来**：

1. 从中止时刻起**恢复上课**，加入对应课程班级；
2. **补全开课以来全部形成性材料**（出勤、作业、实验报告、课程设计、平时测验等）；
3. **参加期末考核**，考核成绩作为该课程最终成绩。

退出需在 3 个工作日内向课程组提交书面说明，由指导教师或项目负责人签字确认。

> [!WARNING]
> 中途退出的成本远高于想象——不仅失去免听资格，还要补全之前落下的全部材料。**申请之前先确认自己能把这个项目做到底。**
