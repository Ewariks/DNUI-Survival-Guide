# 课程指南

这里将整理各年级、各专业课程的学习经验，例如课程学习方法、作业与实验经验、复习资料等。

> 本栏目只整理学习经验与资料，不提供教师或课程评分类内容。

内容正在持续完善。欢迎通过 GitHub Pull Request 参与贡献。

## 计划整理的话题

以下为栏目规划，具体内容以各页面实际发布为准：

- 公共基础课学习经验
- 专业课学习经验
- 作业、实验与课程设计经验
- 复习资料与学习资源
