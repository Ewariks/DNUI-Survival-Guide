# 学生社团

据[校团委介绍](https://xtw.neusoft.edu.cn/2026_07/30_10/content-50124.html)，学校现有**近百个学生社团**，覆盖七大领域：

| 类别 | 主要方向 |
| --- | --- |
| 思想政治类 | 理论学习与社会实践，如国旗护卫、法治宣传、红色主题等方向 |
| 学术科技类 | 机器人、人工智能、大数据、网络安全、游戏开发等技术方向，项目驱动并对接学科竞赛；**数量占比最高**，新兴领域可全年申请注册成立 |
| 文化艺术类 | 艺术团、话剧、汉服、摄影、美术创作、模型设计等 |
| 体育竞技类 | 篮球、武术、轮滑、飞盘、棒球、滑板等，有机会承办校级体育赛事 |
| 志愿公益类 | 社区服务、急救培训、流浪动物救助等志愿服务 |
| 自律互助类 | 心理健康、语言学习、文学阅读、校友服务等朋辈互助 |
| 创新创业类 | 依托大学生创业中心（SOVO），覆盖创意孵化、产品研发、企业管理等环节 |

## 社团嘉年华

每年一度的**「社团嘉年华」**是各社团集中展演和纳新的主要场合，一般在学年初举办。

## 怎么加入

1. 关注学年初的社团嘉年华及各社团纳新推送，现场或线上报名；
2. 没有找到感兴趣的领域？**学术科技类社团支持全年申请注册成立**，满足条件可以自己发起。
