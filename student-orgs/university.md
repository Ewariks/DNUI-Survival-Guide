# 校级组织

校级学生组织由**校团委**指导，面向全校学生运行和纳新。

## 校团委学生会

学校层面的学生组织，每届学生骨干通过**公开选拔**产生，选拔通知一般发布于[校团委网站](https://xtw.neusoft.edu.cn/)的「通知公告」栏目。

## 学生代表大会

学生参与学校民主管理的代表大会机制，学生代表按程序产生。

## 微光网络工作室（Shimmer）

[微光网络工作室](https://shimmer.neusoft.edu.cn/)是学校的 Web 兴趣团队，**负责学校官网及相关产品的开发和维护**——你正在浏览的学校官网（含英文版、日文版）、新闻文化网、[东软 Go! 校内网址导航](http://go.neusoft.edu.cn/)、社团纳新工具等均出自它之手，学校官网页脚的「技术支持」指的就是它。

- 团队规模不大（官网自述「成员不足十人」），由产品和兴趣驱动；
- 开源项目托管在 [GitHub（NeuShimmer）](https://github.com/NeuShimmer)，包括 NeuCMS 等；
- 技术博客「[微光后院](http://shimmer.neusoft.edu.cn/blog/)」。

> [!TIP]
> 对 Web 开发感兴趣的同学可以关注其官网与博客了解动态和纳新信息。
