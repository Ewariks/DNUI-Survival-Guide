# 微光网络工作室 · Shimmer Network Studio

> 坚持心中的微光，梦想在这里起航。

[微光网络工作室](https://shimmer.neusoft.edu.cn/)（Shimmer Network Studio）是大连东软信息学院的学生 Web 技术团队，成立于 2013 年，由学校**品牌发展部与网络与信息中心共同指导**。工作室专注于 Web 技术开发，长期承担**学校官网（中文、英文、日文三个版本）**及新闻文化网等校级网站的设计、开发与维护——学校官网页脚的「技术支持」即由本工作室署名。

## 主要工作与成果

工作室秉持「学以致用」的宗旨，既承担校级平台建设，也自主开发面向师生的产品与服务。代表性成果包括：

### 东小龙系列

「玩 → 攒积分 → 换文创」的校园产品闭环：

- **东小龙连连看**——类「开心消消乐」的休闲消除游戏，游戏过程可累计积分；
- **东小龙拼图**——类「华容道」的滑块拼图游戏；
- **校园打卡**——在校园指定地点实地打卡签到的轻量应用；
- **积分商城**（[go.neusoft.edu.cn](http://go.neusoft.edu.cn)）——游戏所获积分在此兑换文创产品。

上述产品均已正式上线，在校内实际运行，供全校师生日常使用。

### 其他校内应用

- **微聚小程序**：校史答题、云报到合影、语音抽盲盒、DNUI META 换头像等；
- **活动抢票与抽奖系统**；
- **社团纳新工具**；
- 更多作品见[工作室官网](https://shimmer.neusoft.edu.cn/)与 [GitHub（NeuShimmer）](https://github.com/NeuShimmer)（含 NeuCMS 等开源项目）。

## 为什么加入

- **参与真实项目**：团队规模较小（不足十人），不设部门与等级，成员可全程参与需求、设计、开发到上线的各个环节，在校期间即可积累完整的项目经验；
- **产出可展示的作品**：工作室开发的游戏与网站面向全校师生实际使用，作品可直接作为个人能力的有力证明；
- **获得专业指导**：指导教师赖婉芸老师长期参与每周五下午的头脑风暴与技术分享活动，全程陪伴成员成长；
- **氛围自由开放**：无出勤打卡与绩效考核，鼓励成员自主提出想法，倡导「思想自由，兼容并包」；
- **发展前景可期**：往届成员中已有进入 360、字节跳动、滴滴等知名互联网企业者。

## 招募对象

欢迎对 **Web 技术、设计或产品方向**感兴趣的同学加入，涵盖前端、后端、设计、运维、产品等方向。更看重学习意愿与踏实的态度，而非现有水平；也希望加入的同学能够保持参与、避免长期缺席。
