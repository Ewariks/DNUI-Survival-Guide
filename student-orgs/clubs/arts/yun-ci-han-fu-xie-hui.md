# 云辞汉服协会

云辞汉服协会是一家致力于传承和弘扬中国传统文化的社团。主要活动包括汉服日活动、传统文化表演等，旨在让更多的人了解和体验中国传统文化之美。

协会定期举办汉服日，邀请校内同学一同参与，通过展示、讲解和互动体验，让更多人感受汉服之美；还精心策划古乐演奏、舞蹈表演、书法篆刻等传统文化表演，让传统文化焕发新的活力。希望通过这些活动唤起大家对传统文化的兴趣，共同传承和弘扬中华优秀传统文化。

> [!TIP]
> 社团的活动安排与纳新方式可能每年调整，最新信息请以纳新季官方发布为准。欢迎社团成员点击右下角「在 GitHub 上编辑此页」补充与更新。
