# S.R.B-box社

本社团以 Beatbox 口技和说唱文化为核心，汇聚校内喜爱嘻哈音乐的爱好者。日常活动分两大板块：Beatbox 侧重基础鼓点、音色模仿练习，教学气息控制与节奏编排；说唱围绕歌词写作、flow 练习、即兴 freestyle 展开，社员互相交流编曲思路，打磨舞台作品。

社团定期组织队内切磋、校园小型公演，还会联合文艺活动登台表演，以积极向上的原创内容传递青春活力，在节拍与韵脚中丰富课余生活，打造轻松自由的嘻哈交流平台。

> [!TIP]
> 社团的活动安排与纳新方式可能每年调整，最新信息请以纳新季官方发布为准。欢迎社团成员点击右下角「在 GitHub 上编辑此页」补充与更新。
