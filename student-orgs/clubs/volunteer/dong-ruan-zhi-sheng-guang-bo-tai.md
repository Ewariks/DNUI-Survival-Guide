# 东软之声广播台

东软之声广播台 2002 年成立，是校团委直属五大社团之一、校内唯一有声媒体。社团秉持家文化，以声为媒传递校园资讯，开设多档特色栏目，承办点歌台、主持人大赛、配音秀大赛等活动。下设多部门分工协作，依托线上多平台扩大传播，提供播音、剪辑等实践机会，多年来培育众多播音人才，打造温暖有深度的校园声音品牌。

> [!TIP]
> 社团的活动安排与纳新方式可能每年调整，最新信息请以纳新季官方发布为准。欢迎社团成员点击右下角「在 GitHub 上编辑此页」补充与更新。
