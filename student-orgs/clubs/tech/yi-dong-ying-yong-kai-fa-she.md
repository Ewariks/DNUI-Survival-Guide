# 移动应用开发社

移动应用开发社团隶属于计算机与软件学院，设社长、副社长及指导老师。社团分多个项目组，分别推进企业项目协作平台、课程资源管理平台开发，以及基于 OpenGL 的游戏引擎算法研究。社团常态化开展全品类技术培训、一对一项目指导与模拟答辩，以赛促学，曾斩获国家级、省级、校级多项赛事奖项，致力于培养兼具技术能力与创新思维的应用型开发人才。

> [!TIP]
> 社团的活动安排与纳新方式可能每年调整，最新信息请以纳新季官方发布为准。欢迎社团成员点击右下角「在 GitHub 上编辑此页」补充与更新。
