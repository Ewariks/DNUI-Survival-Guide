# 无限空间社

本社团是专注于能力提升的技术型学习社团，旨在为同学们提供系统化、实践性的学习平台。社团以理论为辅、实战为主，学习氛围轻松包容，不设基础门槛——无论有无技术基础，都可以在这里系统学习、互相交流、组队实践。通过日常训练、项目练习和科创实践，全面提升个人软硬件技术水平、创新能力与团队协作能力，为学业提升、竞赛实践和技术积累打下扎实基础。

> [!TIP]
> 社团的活动安排与纳新方式可能每年调整，最新信息请以纳新季官方发布为准。欢迎社团成员点击右下角「在 GitHub 上编辑此页」补充与更新。
