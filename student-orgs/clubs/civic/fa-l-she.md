# 法律社

大连东软信息学院法律社由本校在校学生自愿组成，是面向全校学生的非营利性、学术实践类学生团体，致力于宣传法律知识、弘扬法治思想。社团宗旨是「普及法律知识，弘扬法治精神，锻炼实务能力，服务校园社会」。通过开展各类活动，提高成员的法律素养、逻辑思辨能力与社会责任感，为对法律有兴趣的同学提供学习、交流和实践的平台。凡承认本章程的本校在校学生，对法律有浓厚兴趣，均可申请加入。

> [!TIP]
> 社团的活动安排与纳新方式可能每年调整，最新信息请以纳新季官方发布为准。欢迎社团成员点击右下角「在 GitHub 上编辑此页」补充与更新。
