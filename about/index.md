# 关于项目

DNUI Survival Guide（大连东软信息学院生存指南）是一个由学生共同维护的非官方开源项目，希望帮助每一位 DNUIer 更清楚地度过大学四年。

> [!IMPORTANT]
> 本项目与大连东软信息学院官方无隶属关系，全部内容由贡献者整理，仅供参考，不代表学校立场。

## 项目定位

- 校园 Wiki 与新生指南
- 学习经验库与专业成长指南
- 竞赛经验库
- 实习就业与升学指南
- 学长学姐经验传承平台

## 内容可靠性

本站内容来自学生贡献，我们坚持：

- 不为了填满页面而编造学校政策、收费、宿舍、就业数据等信息；
- 没有可靠内容时，宁可保持「内容正在完善」；
- 经验类内容代表作者个人视角，请结合自身情况判断。

发现内容错误欢迎通过 [GitHub Issues](https://github.com/LuBanQAQ/DNUI-Survival-Guide/issues) 反馈，或直接提交 Pull Request 修正。

## 技术栈与部署

- 站点基于 [VitePress](https://vitepress.dev/) 构建，是纯静态网站，无后端、无数据库。
- 内容以 Markdown 维护，通过 GitHub Pull Request 协作。
- `main` 分支合并后，由 Cloudflare Pages 自动构建并部署。
